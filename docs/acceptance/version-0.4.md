# Version 0.4 acceptance

What 0.4.0 is judged by: a network of bundles, the configuration and its `company:` alias, one index with a collection per bundle, failure and refresh per bundle, identity across bundles, `catalog`, `status` and `pack` per bundle, of [../plans/version-0.2.md](../plans/version-0.2.md), section 3.3 (issue 3; decisions D72 to D76). "Automated" means a test in the suite proves it on every run, at UTC+14 and UTC−11; the two scripted items need a person's reading, as the items of the version 0 runbook do. The version 0 runbook ([version-0.md](version-0.md)) and its instruments keep working against a `company:` file, a network of one bundle, which keeps version 0's lines and the shapes of `catalog` and `status` (D74); this release's runs of them are recorded below.

## The measurement: the corpus as a network

`node bench/run.mjs --split` measures what a network does to a bundle's ranks, over the four unfiltered configurations at limit 5, with two pairings ([../research/benchmark-network.md](../research/benchmark-network.md)); recorded, not gated. The measurement D-D asks for sets each corpus folder, indexed alone, against the same folder in the network of the four (736 pages): 7 of the 100 gold ranks moved, 5 of them in question/relaxed (2 better, 3 worse, those three out of the first five) and one in each keyword configuration (rank 1 to 2), none in question/strict; question/relaxed went from hit@1 17/25 and MRR@5 0.75 alone to 16/25 and 0.68 in the network; and each of the 76 answers that found the gold page in both runs gave it another score. The second pairing, the corpus as one bundle against the same pages split into a collection per folder, is a near no-op by construction (the same pages in one table, only the token `bench` gone from each `filepath`): no gold rank moved, and all 100 top fives held the same pages in the same order (read from the run's records, `<bundle>:<path>` against `<folder>/<path>`). The build recorded only that second pairing and read it as the network's shift, which it cannot show; the fold of the build reviews (C-I-D1) added the first. Both were run at `fd92339`, the corpus at its pinned commits.
